# Web PWA

This is the standalone HeyLane React/Vite app. It uses browser localStorage;
there is no backend to start.

From the repository root:

```powershell
npm run install:all
npm run dev
```

Open http://localhost:5173. Run `npm test` and `npm run build` from the root
for validation. See [the project README](../README.md) for login details.
